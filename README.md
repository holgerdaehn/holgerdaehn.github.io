# holgerdaehn.github.io

Persönliche Website von Holger Dähn, veröffentlicht über GitHub Pages.

## Lokal ansehen

Die Seite besteht aus statischem HTML, CSS und JavaScript. Für eine lokale Vorschau genügt beispielsweise:

```sh
python3 -m http.server 8000
```

Anschließend ist die Seite unter <http://localhost:8000> erreichbar.

## Veröffentlichung

Das Repository wird in den GitHub-Pages-Einstellungen als Quelle für die Website ausgewählt. `robots.txt` verweist auf die XML-Sitemap; die Canonical URL und alle Social-Media-Metadaten zeigen auf `https://holgerdaehn.github.io/`.
